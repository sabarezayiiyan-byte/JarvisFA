# جارویس فارسی
این نسخه یک نمونه اولیه نصب‌شدنی است. قابلیت‌ها: تشخیص گفتار فارسی با سرویس گفتار اندروید، پاسخ صوتی فارسی در صورت پشتیبانی موتور گفتار گوشی، بازکردن کروم/تنظیمات/یوتیوب/ساعت و اعلام درصد باتری.
برای ساخت APK، GitHub Actions به‌صورت خودکار پس از ثبت فایل‌ها اجرا می‌شود. فایل خروجی در بخش Actions و Artifact با نام JarvisFA-APK قرار می‌گیرد.
توجه: بیدارباش دائمی «سلام جارویس»، گفت‌وگوی هوش مصنوعی آنلاین، پیامک/تماس و اجرای کامل آفلاین در این نسخه پیاده‌سازی نشده‌اند.
